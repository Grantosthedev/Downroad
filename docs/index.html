Downroad

macOS app to download YouTube, Instagram, and TikTok videos and images. Trim with in/out points, choose quality, and save clips without pulling the whole file.

Download latest release
  • Partial downloads and quality presets (Best, 1080p, audio only)
  • Instagram carousels and reels · TikTok · YouTube
  • Auto-updates on Wi‑Fi · QuickTime and Premiere-friendly output
  • Open source on GitHub · MIT license
